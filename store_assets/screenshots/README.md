# Screenshots for Google Play

Play Console needs **at least 2 phone screenshots** (up to 8). Screenshots must be real screens of the app – do **not** use mock-ups that show features the app does not have.

## How to take them
1. Install the debug APK (from GitHub Actions → "Build test APK" → artifact) on your phone or an emulator.
2. Add a few real example tasks / a note / one ledger entry so the screens are not empty.
3. Take screenshots with the phone's normal screenshot buttons (portrait).
4. Save them here as `01_home.png`, `02_chat.png`, ... and upload them in Play Console → Store listing → Phone screenshots.

## Suggested shots (in this order)
| # | Screen | What to show |
|---|---|---|
| 01 | Home | Greeting, weather card, progress card, tasks |
| 02 | Home → mic overlay | "Listening..." overlay while speaking |
| 03 | Chat | A real question and the AI's answer (try one English and one Bangla) |
| 04 | Tools → Tasks | A short list of tasks |
| 05 | Tools → Notes | One or two notes |
| 06 | Tools → Ledger | Income/expense entries with totals |
| 07 | Persona | Persona/tone/language settings + About card with logo |

## Size rules (Play Console)
PNG or JPEG, each side between 320 px and 3840 px, the long side at most 2× the short side. A normal phone screenshot already fits.

The logo/icon/feature graphic are already prepared in `../graphics/`.
